## Bridge Required steps
1. `playgama-bridge-config.json` beside `index.html`: OK (zip lists it).
2. Bridge first, initialise before the game: PARTLY. The Bridge script is the first script (`tools/build.js` PLAYGAMA_TAG fills the slot ahead of all game code) and every SDK call waits on `initialize()`; but the game itself does not wait for it before starting (it is one self-contained file with nothing to load, so it starts at once; saves and ads queue behind init).
3. Language from `platform.language`: OK (read after init; English only, declared English only).
4. Storage only through the Bridge: OK (`tools/test/playgama.js`: 0 localStorage calls; reads all keys in one `get`, writes only on progress).
5. Pause and audio state: OK (starts muted until the Bridge answers; verified in Chrome: muted 0 sounds, paused 0 sounds and context suspended, resumed sound back).
6. `game_ready` at the first playable frame: OK by design (no loading screen; sent from `js/main.js` at the first playable frame). Not observed on the live platform.
7. Interstitial at every natural pause, no own counter: OK (every level boundary; the Bridge paces it). Not observed on the live platform.
8. Hide what is unsupported: OK for rewarded (button hidden if unsupported). No store, leaderboard, sign-in or external links exist.
